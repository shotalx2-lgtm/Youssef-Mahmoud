فونتريكس — Arabic Font Library Website
=========================================
هذا موقع ثابت جاهز كبداية، باللغة العربية وبتصميم متجاوب للموبايل والكمبيوتر.

الملفات:
- index.html: الصفحة الرئيسية ومكتبة الخطوط.
- style.css: تصميم الموقع.
- script.js: البحث والتصنيفات والقائمة للموبايل وواجهة تسجيل الدخول التجريبية.\n- font.html: صفحة تفاصيل كل خط وزر الانتقال للتنزيل الرسمي.
- about.html: عن الموقع.
- privacy.html: سياسة خصوصية مبدئية يجب مراجعتها قبل النشر.
- contact.html: صفحة تواصل تحتاج رابطك الرسمي.

مهم:
1. روابط الخطوط الحالية تفتح صفحات الخطوط الرسمية على Google Fonts. لم تُرفع ملفات الخطوط إلى هذا الموقع.
2. المعاينات تعتمد على Google Fonts والإنترنت.
3. لا توجد إعلانات مفعلة، ولا توجد أرباح مضمونة. يلزم نشر الموقع والتقديم لشبكة إعلانية والموافقة عليها.
4. قبل النشر، أضف رابط قناتك أو حساب التواصل في contact.html، وراجع سياسة الخصوصية.
5. لا ترفع خطوطًا لا تملك حق إعادة توزيعها؛ استخدم المصادر الرسمية وتحقق من التراخيص.
6. الموقع غير منشور على الإنترنت بمجرد فك ضغط الملف. يجب رفع الملفات إلى استضافة أو منصة نشر.
